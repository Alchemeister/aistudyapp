# Landing Page - Implementation Notes

## Overview
The landing page should be a separate static site or simple React page that markets the app to new users.

## Recommended Tools
- **Framer** - Easiest, no-code, great templates
- **Webflow** - More control, visual editor
- **Next.js** - If you want code control, good SEO
- **Simple HTML/CSS** - Cheapest, host anywhere

## Structure

```
LANDING PAGE STRUCTURE

HEADER
- Logo + App Name
- Navigation: Features | Pricing | Login
- CTA Button: "Start Free"

HERO SECTION
- Headline: "AI-Powered Study Tools That Actually Work"
- Subheadline: "Upload your textbook, get flashcards, quizzes, and study guides in seconds."
- CTA: "Start Studying Free" (large button)
- Demo Video/GIF showing PDF → Flashcards generation

SOCIAL PROOF
- "Join 1,000+ students" (update as you grow)
- University logos (if any partnerships)
- Star rating

FEATURES GRID (3-4 items)
1. AI Flashcard Generation
   - Icon + "Upload PDF, get flashcards instantly"
2. Smart Quizzes
   - Icon + "Test yourself with AI-generated questions"
3. Spaced Repetition
   - Icon + "Never forget with proven SRS algorithm"
4. Cloud Sync
   - Icon + "Study anywhere, any device"

HOW IT WORKS
Step 1: Upload your textbook PDF
Step 2: AI extracts and organizes chapters
Step 3: Generate flashcards, quizzes, notes
Step 4: Study smarter, score higher

PRICING TABLE
- FREE: 50 generations, 3 courses - $0
- PRO: Unlimited, cloud sync - $8/mo
- STUDENT: Pro features - $5/mo (with .edu)

TESTIMONIALS (when you have them)
- Student quotes with photos
- "Raised my GPA from 2.8 to 3.5"

FAQ
- What file types are supported?
- How does the AI work?
- Can I cancel anytime?
- Is my data secure?

FOOTER
- Links: About, Privacy, Terms, Contact
- Social: Twitter, Discord, etc.
- Copyright

CTA BANNER
- "Ready to ace your exams?"
- Final signup button
```
